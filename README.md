# Simple Interest Calculator

## Project Description

This project is a simple interest calculator written in Bash. It calculates the simple interest based on the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal amount
- Annual rate of interest
- Time period in years

## Output

The program displays the calculated simple interest.
